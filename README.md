# Valcendre : l'horloge aux énigmes

Cette nuit, la grande horloge de Valcendre s'est arrêtée. Ses 30 rouages ont roulé dans toute la ville, et chaque habitant ne rend le sien qu'à qui résout son énigme.

- **Trois quartiers**, chacun avec son habitant :
  - le Marché et Mme Brindille ;
  - le Port et Octave le passeur ;
  - la Tour de l'Horloge et Ysé l'archiviste.

  Résoudre 7 énigmes d'un quartier ouvre le suivant.
- **30 énigmes** : logique, calcul, déduction et devinettes. Certaines se manipulent : les lanternes à allumer, les caisses à faire glisser, le carré magique.
- **Étincelles et indices** :
  - Chaque énigme vaut des étincelles. Une mauvaise réponse en retire un peu, jusqu'à la moitié de sa valeur au plus.
  - Les bougies allument les indices. Chaque énigme résolue t'en rend une.
- **Une explication** après chaque énigme, et une fin quand l'horloge repart.

La partie est gardée par NeoBase, synchro comprise. Le plugin ne demande qu'une seule autorisation, `storage` (ses propres données) : il tourne dans le bac à sable de NeoBase.

## Installer

Dans NeoBase : **NeoStore → À découvrir → Valcendre → Installer**.

Développer un plugin : voir le [SDK NeoBase](https://github.com/NDesumeur/neobase-sdk).
